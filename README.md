# jmiralva.me

Personal portfolio website for Jorge Mir Alvarez, a product manager based in Chicago.

## Tech Stack

Built with [Astro](https://astro.build/) - a modern static site generator optimized for performance.

## Development

```bash
npm install    # Install dependencies
npm run dev    # Start dev server
npm run build  # Build for production
```
